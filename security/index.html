SECURITY & GOVERNANCE

Evidence integrity and controlled human disposition are product requirements.

Tallyridge is designed around bounded access, source provenance, deterministic financial logic where appropriate, and explicit review gates for sensitive municipal decisions.

Least-privilege access

Role-scoped access should separate ingestion, review, approval, administration, and export capabilities.

Source provenance

Every finding should retain the authoritative source records, import metadata, rule version, and calculation path used to produce it.

Immutable approvals

Approved rule versions and reviewer dispositions should be append-only and attributable to an authorized user.

Human review gates

Legal authority, collectibility, refunds, exemptions, accounting changes, and restricted-use decisions should never be autonomously finalized.

Data minimization

Baselines should ingest only fields necessary for the scoped assurance tests, with retention and deletion rules defined contractually.

Exportable evidence

Agency staff should be able to reproduce the basis for a finding without relying on an opaque model response.

PRODUCTION NOTE

Security controls must be commissioned against the final hosting, database, identity, and integration architecture.

This deployment package is a public-facing static GTM and synthetic demonstration surface. It intentionally contains no production municipal data, credentials, database connection, or authentication layer.
