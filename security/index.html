PUBLIC SURFACE HARDENED
SECURITY & ARCHITECTURE

Evidence integrity and controlled human disposition are product requirements.

The public GTM surface is intentionally separated from any future municipal production data plane. Tallyridge’s operating doctrine requires bounded access, source provenance, deterministic calculations where appropriate, explicit review gates, and exportable evidence.

Public deployment posture

What this public environment does—and does not—contain.

Enterprise credibility starts by not implying controls or integrations that have not been commissioned.

NO PRODUCTION DATA

Synthetic-only demonstration

No production municipal records, credentials, source-system secrets, or authentication tokens are embedded in this public deployment.

NO AUTONOMOUS DISPOSITION

Human authority preserved

Financial, legal, refund, exemption, accounting, and restricted-use decisions remain with authorized agency personnel and counsel.

NO HIDDEN MODEL AUTHORITY

Evidence over opaque inference

Where calculations are used, the basis should remain inspectable through source records, rule chronology, normalized inputs, assumptions, and reviewer disposition.

Security model
LP

Least privilege

Production roles should separate ingestion, review, approval, administration, export, and integration capabilities.

SP

Source provenance

Every finding should retain authoritative sources, import metadata, rule version, calculation path, and evidence status.

IA

Immutable approvals

Approved rule versions and reviewer dispositions should be append-only, timestamped, and attributable to an authorized identity.

HG

Human review gates

Sensitive classifications must be reviewable before they become financial, legal, or policy action.

DM

Data minimization

Only fields necessary for the scoped assurance tests should be ingested, with explicit retention and deletion requirements.

EX

Exportable evidence

Agency staff should be able to reproduce the basis for a finding without depending on a hidden model conversation.

Web hardening

Controls active on this GTM deployment.

  • Strict Transport Security from Vercel edge
  • Content Security Policy scoped to same-origin assets
  • Frame embedding blocked
  • MIME sniffing disabled
  • Referrer leakage constrained
  • Camera, microphone, and geolocation disabled
  • Dedicated security.txt disclosure route
  • No third-party analytics or advertising scripts
Production commissioning

Controls required before municipal data is onboarded.

  • Tenant isolation and managed database architecture
  • SSO / MFA / RBAC and separation of duties
  • Encryption and key-management policy
  • Connector-specific credentials and secret rotation
  • Append-only audit history and evidence retention
  • Backup, recovery, incident response, and observability
  • Agency-specific retention and deletion controls
  • Security review and procurement documentation
